# anker-trial-skills

安克创新「AI 飞行员试炼」备考 skill 集。**全部为"参考／检查单"类，不替用户下判断、不替用户生成指令**——否则反伤试炼 Prompt 分项。

## 结构（每个子目录 = 一个 skill，Claude Code / WorkBuddy 通用格式）

| skill | 绑定阶段 | 触发 |
|---|---|---|
| `anker-boot-check` | 学习段/轮0 | 开考第一步：官方教学提醒 + 环境验证 + 建文件夹 + 路径声明 |
| `anker-scoring-rubric` | 轮10/11/13 | 整合前、交卷前做评分自检 + "方法复用"一节 |
| `anker-isr-map` | 轮2/5a·5b·5c/7/9 | 要框架 / 填 Insight（**三次交互**）/ 填 Strategy / 填 Operation（调时指明哪一段） |
| `anker-read-problem` | 轮1 | 开始读材料前走读题四问 + 秒回验伪 |
| `anker-challenge-triggers` | 轮8(触发)/轮6 | 命中7条件才质疑；轮6 让 AI 反驳我 |
| `anker-coverage-check` | 轮7 | 填 Strategy 时查方案五侧面 + MECE |
| `anker-demo-spec` | 轮0/12 | 定全局约束 / 做 Demo 的无网硬约束 |
| `anker-vague-rewrite` | 轮10 | 整合前虚词清零 |
| `anker-role-brief` | 轮0 | 定全局约束时的角色定义结构 |

## 设计铁律
- skill 输出 = 「该覆盖的清单 / 该问自己的问题 / 该守的约束」→ OK
- skill 输出 = 「替你写好的指令 / 替你做的分析」→ NO
- 每个 skill 的 `description` 写死触发轮次/条件，不写宽触发（不过载）。

## 部署（考场侧）
1. 本仓库 = **9 个 skill + docs/ 两份作战手册**（`完整打法.html` / `答题执行手册.html`），一次 clone 全带走。
2. 考场云桌面激活后：
   ```
   git clone https://github.com/feiyu1215/anker-trial-skills .claude/skills
   ```
   → 9 个 skill 自动识别（可用性 ≠ 激活，按轮调用）；
   → 浏览器 file:// 打开 `docs/答题执行手册.html`（P0–P13 复制+填空）和 `docs/完整打法.html`（时间表+纪律）。
3. 私有库，仓库内不含任何账号凭据。

### ⚠️ 云桌面可能没网 —— 必须有离线兜底

`git clone` **依赖网络**。而本套文档自己就在反复强调"云桌面可能没网"（手册 P4 无网降级分支、P12 Demo 无网硬约束）——
如果开考后才发现 clone 不通，**9 个 skill 全部拿不到**。两条路都提前备好：

| 场景 | 做法 |
|---|---|
| **云桌面有网** | 用上面的 clone 命令。私有库需已登录 GitHub，或考前把仓库临时设为 public（仓库内无凭据） |
| **云桌面没网** | 考前把仓库打包成 `anker-trial-skills.zip` 带上（U 盘 / 网盘 / 邮件附件），在云桌面里解压到工作目录的 `.claude/skills/` 下，**效果与 clone 完全一致** |
| **本地想直接生效** | 把 9 个 skill 目录复制到用户级目录：`~/.workbuddy/skills/`（Windows：`C:\Users\<你的用户名>\.workbuddy\skills\`），WorkBuddy 自动识别 |

> 开考前的 **30 分钟体验时间**正是用来试这个的：先确认能不能联网、能不能 `git clone`，再决定走哪条路。

## 关键约定（改任何一份文档前先看这里）
1. **Prompt 唯一正本 = 《答题执行手册》**。《完整打法》里涉及 prompt 的地方一律放指针（"完整指令见手册 Px"），**不在打法里重写**——两份文件写两遍必然漂移。
2. **时间轴**（3h 主表）：学习 `0–20` 与提交 `165–180` 是**硬成本**；轮 5 是 **5a/5b/5c 三次交互**（不是一轮）；轮 8 虽是触发式，但**至少会触发一次**，`116–123` 已为它预留 7 分钟；轮 10 的 10 分钟里**含 5 分钟回补轮 9 的指标表**。
3. 两份文档的**时间表已同步**（打法 ③ ↔ 手册 B 表），改一处必须同步改另一处。
4. 2h 场景用打法 ③ 的压缩列，不要自己另算。
