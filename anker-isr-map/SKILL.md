# ISR × M1–M10 要点地图（参考／检查单）

> 铁律：本 skill 只告诉你"这段必须产出什么、最易漏什么"，不替你做分析、不替你写结论。

## 骨架段（轮2：先要框架，不要方案）
ISR 三段：Insight(洞察)→Strategy(策略)→Operation(执行)。先让 AI 给骨架，你自己先有判断再完善。
- 时间账：学习 + 提交是硬成本（3h 考试扣掉 35 分钟）；Insight 侧四个动作（交叉/补盲/填/压测）合计约占解题时间四成——评委看思考深度的地方，别省；提交硬留 15 分钟。

## M1–M6 段（轮5：诊断，务必做透）
> ⚠️ **这一块是三次交互，不是一次**：对应手册 P5-a（问题判断与证据链）／P5-b（分层 + 漏斗）／P5-c（根因链）。
> 每块都要它复述、你确认，再进下一块。**按"一轮"的节奏赶，被砍掉的一定是 Insight 的深度——而 Insight 是评分大头。**
| 模块 | 必须产出 | 最易漏 |
|---|---|---|
| M1 收益风险盘点 | 核心结果指标(看题定)+收益算法+风险红线 | 只盯单环节忽略关联恶化；不提前交代缺什么数据 |
| M2 漏斗拆解 | 环节口径+转化率/流失率/绝对流失量+下钻+环比 | 只看转化率不看绝对量；只看总漏斗不下钻 |
| M3 反馈分类 | 来源+样本量+两维分类+频次占比+情绪加权 | 不标频次(3人vs3000人)；反馈不挂环节 |
| M4 用户+场景分层 | 分层并回挂漏斗(哪类人在哪环掉最狠) | 分层完不回挂=自嗨；只分用户不分场景 |
| M5 交叉定位 | 数据断点↔反馈热点找张力，回头修正初判 | 不做"更新"步=初判走到黑；只信一方 |
| M6 根因链 | 现象→机制→原因→结果 四段，标证据 | 把现象当根因；跳过"机制"层 |

## M7–M8 段（轮7：策略）
- M7 候选方案≥2 + ROI量级 + 不采纳方向及理由（方案不映射回根因=没用）。
- M8 优先级(ICE/RICE) + 动作六要素(目标用户/触发场景/展示/频次节奏/与现有关系/成功判定) + "不做什么" + 代价取舍。
- 触达类必给：触发条件+频次上限+观察周期。

## M9–M10 段（轮9：落地）
- M9 三类指标(核心/过程/护栏) + 成功/失败/回滚三线 + 灰度节奏 + 回滚预案（**漏护栏指标最多人漏**）。
- M10 全量复盘 + 长尾观察 + 风险收口 + 成体系交付目录（评委倒查找不到=白做）。

> 具体指标/分层维度/环节数量一律按当题业务定，不套固定模板。这是体检表不是填空表。
