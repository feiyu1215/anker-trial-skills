# 虚词清零（参考／检查单）

> 铁律：本 skill 只给你"哪些词验收不了、怎么改"，你对自己的草稿逐条改；不替你改写、不替你下判断。

## 重点排查词
适当、合理、优化、提升、加强、确保、持续、尽快、显著、大幅。

## 改写方法
每条模糊词必须改成**能被第三方判定"做到还是没做到"**的可量化/可验收标准（给数值/阈值/观察窗口/判定方式）。改不了的标"此处无法验收"，你来决定补证据还是砍。

## 7 条例证（形状示范，内容按题替换）
| 模糊 | 可验收改写 |
|---|---|
| 确保进度顺利 | 第3周完成80%测试用例，通过率≥95% |
| 适当提醒用户 | 用户在［环节］停留>30s且无操作提示1次；同用户24h内最多1次 |
| 提升用户满意度 | 完成后7日内评分≥4.2，有效样本≥200 |
| 优化推荐效果 | 点击率相对提升≥5%，95%置信区间下界>0 |
| 加强风险控制 | 异常订单拦截率≥99%，误拦率≤0.5%，超阈值自动熔断告警 |
| 持续迭代优化 | 每两周复盘，按［指标］决定继续/调整/停止，连续2周期无改善即停 |
| 降低运营成本 | 单次人工处理时长下降≥20%（对比改动前4周同口径均值） |
