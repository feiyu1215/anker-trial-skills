# 读题四问 + 先验 AI（参考／检查单）

> 铁律：本 skill 只给你四个自问 + 一个验伪动作，答案必须你自己给；不替你读题、不替你下判断。

## 四问链（按顺序，别跳）
1. **关键术语是什么**：题干每个专有名词你能不能用自己话解释？解释不了的标出来——那正是让 AI 补的课，也是你之后判它对错的抓手。
2. **业务流程是什么**：钱/物/信息从谁流向谁、过哪几步？画不出=还没懂这题业务，此时问 AI=被牵着走。
3. **问题到底出在哪**：先自己给位置判断（哪一环/哪类对象），再去和 AI 比——有你的一版才有"差异"可看。
4. **最后到底要解决什么**：落到"支持谁做什么决策"——决定交付物骨架，也决定哪些材料是干扰项。

## 秒回验伪（开第一句后做）
- 太快、太顺、太通用的回答，先怀疑它没吃到你的材料和约束。
- 直接问："你是谁 / 你读到了哪些材料"——确认状态再往下走。
