# Demo 无网硬约束（参考／约束声明）

> 铁律：这是你写给 AI 的"Demo 指令必须包含的约束"，你按本题填。不替你写网页、不替你生成指令。

## 你的 Demo 指令必须包含这些约束
- 生成**纯静态单页 HTML**，不依赖任何外网 CDN、外部字体或 JS 库（云桌面可能没网）。
- 双击浏览器能打开；中文 **utf-8** 不乱码。
- 图表用**纯 CSS 或内联 SVG 手写**，不要引 Chart.js / ECharts。
- 不要生成需要 npm install 或构建的项目（只要单文件）。
- 流程：先给结构大纲（不要直接写代码）→ 确认 → 生成 v1（样式从简，先确认信息对不对）→ 补视觉 → 自检。

## 致命项（头号死法）
引 CDN/在线字体/JS 图表库 → 无网直接白屏。生成 React/Vite 要 npm install，无网又耗时直接崩。让它自己编数据 → 和前面分析对不上，评委一对照就穿帮。

## 自检清单（生成后逐条确认）
① 有无外链资源（有就内联化或删）② 中文编码对不对 ③ file:// 直接打开正不正常 ④ 有无没分析过的编造数据。

## 只剩 10 分钟（极简降级，其余全砍只留三块）
① 顶部一句话核心结论；② 漏斗断点图（纯 CSS 横条，标 Top 2~3 断点）；③ 动作表（含触发条件 / 频次上限 / 观察周期）。
三块已能证明"定位准、能落地"，比摊大饼每块都薄强。所以 v1 应在产出段边做边出，别等整合完才从头开始。
